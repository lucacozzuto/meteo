🧳 Arrivi Turistici nel Mediterraneo

Serie storica mensile (1990–2026) degli arrivi in strutture ricettive nei 5 principali paesi dell'Europa Mediterranea basata sui dati Eurostat (dataset tour_occ_arm).

🇮🇹 Turisti Totali Mensili – Italia

ℹ️ Come interpretare il grafico

  • Le 3 Categorie Disponibili:
    • Turisti Totali (TOTAL): Somma complessiva di turisti stranieri e residenti.
    • Turisti Stranieri / Esteri (FOR): Arrivi di visitatori provenienti dall'estero.
    • Turisti Locali / Residenti (DOM): Arrivi di cittadini residenti nello stesso paese.
  • Valori in Cella: Espressi in milioni di arrivi (es. 18.9 = 18.900.000 persone).
  • Grafico Superiore (Mesi Gen–Dic): Scala cromatica indipendente calibrata sull'intensità dei singoli mesi.
  • Grafico Inferiore (TOTALE): Somma annuale degli arrivi su un secondo subplot dedicato.
  • 🟢 Bordo Verde Brillante: Identifica il record assoluto storico per quel determinato mese (o per il totale annuale).
  • Fonte Dati: Eurostat REST API (Dataset tour_occ_arm).
